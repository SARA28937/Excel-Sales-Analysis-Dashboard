# 📊 Excel Sales Analysis Dashboard

## 📌 Project Overview

This is my first Data Analysis project using Microsoft Excel.

The project focuses on analyzing sales data, performing data cleaning and preparation, and creating an interactive dashboard to generate meaningful business insights.

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Pivot Tables
- Pivot Charts
- Slicers
- Data Visualization
- Dashboard Design

## 🧹 Data Cleaning

Before building the dashboard, the raw data was cleaned and prepared for analysis.

The cleaning process included:
- Identifying and handling missing values
- Removing duplicate records
- Standardizing data formats
- Checking data consistency
- Preparing the dataset for analysis

## 📊 Dashboard

The interactive dashboard provides an overview of sales performance, including:

- Total Sales
- Average Sales Quantity
- Total Customers
- Sales by Region
- Sales by Category
- Top 10 Customers
- Top 10 Cities

The dashboard also includes interactive slicers to filter the analysis by region.
